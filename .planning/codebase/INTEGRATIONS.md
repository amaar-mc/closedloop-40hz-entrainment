## File Format Details

**EEG Data (.set + .fdt pair):**
- `.set` files are MATLAB v7.3 format (HDF5 internally)
- Read via `h5py` in `src/data_loader.py`
- Top-level HDF5 keys (no `EEG` wrapper group)
- Actual EEG data in companion `.fdt` files: raw float32
- **CRITICAL:** `.fdt` data is Fortran/column-major order -- use `np.reshape(..., order='F')`
- 19 channels total at 250 Hz sampling rate
- 7 frontal channels selected: Fp1, Fp2, F7, F3, Fz, F4, F8 (10/20 system)
- Already preprocessed by Makoto's pipeline (1 Hz highpass, 50 Hz notch, ICA, CAR)

**Events (.tsv):**
- Tab-separated columns: `onset`, `duration`, `value`
- `value=1` = rest period, `value=2` = stimulation period
- Read via `pd.read_csv(tsv, sep='\t')` in `temporal_multiscale/build_multiscale_dataset.py`
- Used for stim-context features in temporal dataset and epoch-level PAC assignment

**BIDS Metadata:**
- `dataset_description.json` - Dataset-level metadata, generated by bids-matlab-tools v8.0
- `participants.tsv` / `participants.json` - Subject demographics
- `*_eeg.json` - Per-subject recording parameters
- `*_channels.tsv` - Per-subject channel descriptions

## Data Processing Pipeline

**Stage 1: Raw BIDS to Processed Windows**
- Script: `src/data_loader.py`
- Input: `data/raw/ds005048/` (BIDS .set/.fdt files)
- Dependencies: `h5py`, `mne`, `src/preprocessing.py`, `src/pac_computation.py`
- Processing steps:
  1. Load .set metadata via h5py, read .fdt binary data
  2. Select 7 frontal channels
  3. Apply `src/preprocessing.py`: bandpass 0.5-80 Hz (4th-order Butterworth), notch 50 Hz (Q=30), artifact rejection (100 uV), CAR
  4. Segment into 2-second windows (500 samples), 50% overlap (1-second hop)
  5. Compute PAC via `src/pac_computation.py`: Tort (2010) Modulation Index, theta 4-8 Hz phase x gamma 38-42 Hz amplitude
  6. PAC assigned at epoch level (20-40s blocks), shared across constituent 2s windows
- Output: `data/processed/{train,val,test}_data.npz`
  - `windows`: `(n, 1, 7, 500)` - EEG windows
  - `pac`: `(n,)` - PAC labels (range 6e-6 to 7e-4, mean ~4.4e-5)
  - `subjects`: `(n,)` - Subject IDs
- Total: 17,283 windows (11,736 train / 2,725 val / 2,822 test)

**Stage 2: Spectral Feature Caching**
- Generated as part of temporal pipeline
- Output: `data/processed/{split}_spectral_cache.npy`
- 61-dimensional spectral features per window (FFT-based)
- Cached to avoid recomputation

**Stage 3: Multiscale Temporal Dataset**
- Script: `temporal_multiscale/build_multiscale_dataset.py`
- Input: Stage 1 `.npz` outputs + Stage 2 spectral caches + BIDS `events.tsv`
- Feature construction (73 dimensions per timestep):
  - 61 spectral features (FFT power in frequency bands)
  - 7 PAC-derived features (current PAC + causal moving averages at multiple scales)
  - 5 stim-context features (stim_state, time_since_switch, stim_frac_recent, cycle_phase_sin, cycle_phase_cos)
- Sequence construction: lookback=20 steps -> predict horizon=5s ahead
- Z-score normalization with scalers saved for inference
- Output: `data/processed/multiscale_temporal_lb20_hz5_ts1/`
  - `{train,val,test}_multiscale.npz`: `x_seq` (n, 20, 73), `y_future_norm`, `y_delta_norm`, `last_pac`
  - `scalers.npz` - Feature normalization parameters
  - `metadata.json` - Build config and subject splits
- Sequences: 11,160 train / 2,605 val / 2,678 test

## Real-time & Streaming

**Real-time Inference Pipeline:**
- Module: `temporal_multiscale/realtime_inference.py`
- Class: `RealtimePACForecaster`
- Pattern: Rolling causal buffer with deque; accumulates 73-dim feature vectors at 1 Hz
- Input per step: spectral_features (61,), pac_current, stim_state, time_since_switch, stim_frac_recent, cycle_phase_sin/cos
- Requires lookback=20 steps of history before first prediction
- Loads checkpoint + scalers, applies z-score normalization, runs TCN inference
- Target latency: <50 ms per prediction (configured in `config.yaml`)

**Simulation Loop:**
- `src/simulator.py::EntrainmentSimulator` - Exponential PAC dynamics at 1 Hz decision rate
- `src/validation.py::SimulationValidator` - Runs 4 control strategies (Fixed, Reactive, Predictive, Oracle) in parallel
- `run_tcn_validation.py` - Real-data replay with 6 controller variants on all 35 subjects
