**AudioEngine class (~60 lines, placed before Streamlit UI code):**
```python
class AudioEngine:
    SAMPLE_RATE = 44100
    CLICK_FREQ = 40  # Hz — matches research protocol

    def __init__(self):
        self.stimulating = False  # Set by simulation loop
        self.muted = False        # Set by mute toggle
        self.phase = 0
        self.stream = None
        # Pre-generate one period of 40 Hz click train
        period_samples = self.SAMPLE_RATE // self.CLICK_FREQ  # ~1102
        self.click_period = np.zeros(period_samples, dtype=np.float32)
        # 1ms click burst of 1kHz sine at start of each period
        click_n = int(0.001 * self.SAMPLE_RATE)  # 44 samples
        t = np.arange(click_n, dtype=np.float32) / self.SAMPLE_RATE
        self.click_period[:click_n] = 0.3 * np.sin(2 * np.pi * 1000 * t)

    def callback(self, outdata, frames, time_info, status):
        """Sounddevice callback — runs in audio thread."""
        if self.muted or not self.stimulating:
            outdata[:] = 0
            return
        for i in range(frames):
            outdata[i, 0] = self.click_period[self.phase % len(self.click_period)]
            self.phase += 1

    def start(self):
        self.stream = sd.OutputStream(
            samplerate=self.SAMPLE_RATE, channels=1,
            callback=self.callback, dtype='float32'
        )
        self.stream.start()

    def stop(self):
        if self.stream:
            self.stream.stop()
            self.stream.close()
            self.stream = None
```

Guard the entire `AudioEngine` class behind `if AUDIO_AVAILABLE:` or define a no-op stub when sounddevice is unavailable so the rest of the code doesn't need conditional checks everywhere.

- Store all simulation state in session_state: controllers dict, simulators dict, PAC history lists, action history lists, current step, audio engine reference
