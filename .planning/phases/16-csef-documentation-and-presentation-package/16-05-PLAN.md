**March 3-5, 2026 — Feature Ablation Study Design**
- Hypothesis: Spectral EEG features may cause overfitting because they encode subject-specific anatomy rather than generalizable dynamics
- Experiment: Designed systematic ablation study — train identical TCN architecture on 6 different feature subsets (all 73, PAC+stim 12, PAC only 7, PAC+stim+10 spectral 22, spectral+PAC 68, spectral only 61)
- Method: Same MultiscaleCausalTCN (h=64, 4 causal dilation layers), identical training protocol, hold-out test evaluation on 6 unseen subjects

**March 6-8, 2026 — Feature Ablation Results**
- Results: PAC+stim (12 features) achieves test R2 = 0.558, compared to all-features (73) test R2 = -0.025. Spectral-only features produce R2 = -0.420 on test (worse than random). The val-test gap drops from 0.358 (73 features) to 0.246 (12 features).
- Conclusion: Spectral features are the primary source of cross-subject overfitting. The 12 PAC trajectory and stimulation context features capture the causal dynamics that generalize.

**March 10-12, 2026 — Multi-Seed Robustness Validation**
- Hypothesis: The improvement is not seed-dependent
- Experiment: Trained h=64 TCN with PAC+stim features across 5 random seeds (42, 123, 456, 789, 2024)
- Results: Mean test R2 = 0.606 +/- 0.032, range 0.558-0.647. Improvement is robust.
- Conclusion: The finding is reproducible. Feature selection, not architecture or initialization, drives the improvement.

**March 13-14, 2026 — Architecture Search on PAC+Stim Features**
- Experiment: Tested TCN with hidden sizes 32, 64, 128 and varying regularization on the 12-feature set
- Results: h=32 high-reg achieves R2 = 0.613 with only 5,154 parameters. h=128 reaches 0.645 but is 17x larger. Best efficiency: small model + right features.

**March 15-17, 2026 — 4-Channel Configuration and Horizon Sweep**
- Experiment: Evaluated 12-feature TCN on 4-channel (Muse 2 compatible) data. Ran horizon sweep at 1, 3, 5, 8, 10 seconds.
- Results: 4ch test R2 = 0.430 (vs 0.117 persistence). 7ch horizon sweep: R2 = 0.725 (1s), 0.607 (3s), 0.577 (5s), 0.370 (8s), 0.669 (10s). Persistence collapses to negative at 8+ seconds.
- Conclusion: Temporal context compensates for spatial coverage loss. The 4ch configuration is viable for consumer-grade EEG deployment.
