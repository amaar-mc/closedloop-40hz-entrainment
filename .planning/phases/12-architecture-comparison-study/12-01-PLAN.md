Create temporal_multiscale/comparison_models.py with:

1. **SimpleLSTM** (nn.Module): 2-layer LSTM operating on (B, T, F) spectral features.
   - __init__(n_features: int, hidden: int = 64, num_layers: int = 2, dropout: float = 0.1)
   - Architecture: nn.LSTM(n_features, hidden, num_layers, batch_first=True, dropout=dropout if num_layers>1 else 0.0) -> nn.LayerNorm(hidden) -> nn.Linear(hidden, hidden) -> nn.SiLU() -> nn.Dropout(dropout) -> nn.Linear(hidden, 1)
   - forward(x: torch.Tensor) -> torch.Tensor: takes last LSTM timestep, returns (B,) scalar predictions
   - Target ~62K params at hidden=64, 49 features

2. **SimpleTransformer** (nn.Module): Causal TransformerEncoder with causal mask.
   - __init__(n_features: int, d_model: int = 64, nhead: int = 4, num_layers: int = 2, dropout: float = 0.1)
   - Architecture: nn.Linear(n_features, d_model) -> nn.TransformerEncoder(nn.TransformerEncoderLayer(d_model, nhead, dim_feedforward=d_model*2, dropout, batch_first=True), num_layers) with causal mask -> nn.Linear(d_model, 1) on last timestep
   - forward(x: torch.Tensor) -> torch.Tensor: applies causal mask via torch.triu(..., diagonal=1).bool(), returns (B,) predictions
   - The causal mask is `mask = torch.triu(torch.ones(T, T, device=x.device), diagonal=1).bool()` — True means "do not attend"
   - Target ~70K params at d_model=64, 49 features

3. **train_pytorch_model** function: Generic training loop for any nn.Module that takes (B,T,F) and outputs (B,).
   - Signature: train_pytorch_model(model, train_ds, val_ds, test_ds, scalers, device, epochs=80, batch_size=128, lr=1e-3, weight_decay=1e-3, patience=20, grad_clip=1.0, seed=42) -> dict
   - Uses HuberLoss, AdamW, ReduceLROnPlateau(mode="max", factor=0.5, patience=5)
   - Gradient clipping with max_norm=grad_clip
   - Early stopping on val_future_r2 with given patience
   - Denormalizes predictions using scalers (y_future_mean, y_future_std) before computing final test R2/RMSE
   - Returns summary dict: {"model_name", "n_params", "best_epoch", "val_r2", "test_r2", "test_rmse", "test_corr", "train_seconds"}
   - Reuse _r2, _rmse, _metrics, _denorm from train_multiscale_tcn.py (import them, don't copy)

4. **train_xgboost_model** function: XGBoost regression on flattened sequences.
   - Signature: train_xgboost_model(dataset_dir: Path, seed: int = 42) -> dict
   - Flatten (N, T, F) -> (N, T*F). Use x_seq directly (already normalized).
   - XGBRegressor(n_estimators=300, max_depth=6, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, n_jobs=-1, verbosity=0, random_state=seed, early_stopping_rounds=20)
   - Fit on train, use val for early stopping, evaluate on test
   - Denormalize predictions (y_future from NPZ is raw, x_seq is normalized — load y_future directly from NPZ, NOT y_future_norm)
   - Returns same summary dict format as train_pytorch_model

5. **set_seed** utility: random.seed + np.random.seed + torch.manual_seed + cuda.manual_seed_all + cudnn.deterministic=True + cudnn.benchmark=False

Include module-level docstring explaining the purpose. Use `from __future__ import annotations`. Use Path(__file__).resolve().parents[1] for ROOT. Follow repo coding conventions (PEP 8, type hints, standard aliases).

**Implementation:**

1. Dataset path resolution:
   - 4ch: data/processed/muse_4ch/multiscale_temporal_lb20_hz5_ts1/
   - 7ch: data/processed/multiscale_temporal_lb20_hz5_ts1/
   - For horizon != 5, build the dataset on-the-fly using build_multiscale_dataset (import from temporal_multiscale.build_multiscale_dataset). Dataset path pattern: {base}/multiscale_temporal_lb20_hz{H}_ts1/ for 7ch, {base}/muse_4ch/multiscale_temporal_lb20_hz{H}_ts1/ for 4ch.
   - For horizon == 5, the datasets already exist on disk at the paths above — skip rebuild.
   - CRITICAL: Always use target_smooth_window=1 (ts1). Never ts5.

2. For each (dataset, horizon) combination, run each selected model:
   - **persistence**: Call persistence_baseline() from sweep_horizons.py
   - **ridge**: Call ridge_baseline() from sweep_horizons.py
   - **lstm**: Instantiate SimpleLSTM(n_features), call train_pytorch_model()
   - **xgboost**: Call train_xgboost_model(dataset_dir, seed)
   - **transformer**: Instantiate SimpleTransformer(n_features), call train_pytorch_model() with lr=1e-4 (lower LR per research — Transformer training instability at high LR)
   - **tcn**: Instantiate MultiscaleCausalTCN(ModelConfig(n_features)), call train_pytorch_model()

3. Collect all results into a list of dicts, one per (model, horizon) pair. Each dict: {"model", "horizon", "dataset", "test_r2", "test_rmse", "n_params", "train_seconds"}

4. Write results to results/comparison_table_{dataset}.json for each dataset. Also print a formatted ASCII table to stdout.

5. Add a --dry-run flag that only checks datasets exist and prints what would be run, without training.

- n_features = 49 for 4ch, 73 for 7ch (read from metadata.json)
- Transformer lr=1e-4 (half the default), all others lr=1e-3
- XGBoost needs flattened input — handled inside train_xgboost_model
- All models use seed=42 for the primary run (multi-seed is Plan 02)
- Report test R2 and RMSE, not val
