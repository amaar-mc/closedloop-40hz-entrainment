Structure with 8 subsections:

**4.1 Dataset and Preprocessing**
- OpenNeuro ds005048 v1.0.1 (Lahijanian et al., 2024; cite Naeini 2022 for data description)
- 35 dementia patients from memory clinic in Tehran
- 19 monopolar EEG channels (10/20 system), 250 Hz sampling rate
- BIDS-compliant format; already preprocessed with Makoto's pipeline (1 Hz HP, 50 Hz notch, ICA, CAR)
- Our additional preprocessing: bandpass 0.5-80 Hz, 50 Hz notch, artifact rejection (+/-100 uV threshold), common average reference
- Artifact rejection applied BEFORE CAR to prevent corrupted channels from propagating
- 7 frontal channels selected: Fp1, Fp2, F7, F3, Fz, F4, F8
- Segmentation via BIDS events.tsv: 40s Stimulus + 20s Rest epochs
- 2-second sliding windows (500 samples), 1-second hop (50% overlap)
- Subject-level splits: 24 train / 5 val / 6 test (seed=42)
- 17,283 total windows: 11,736 train, 2,725 val, 2,822 test

**4.2 Phase-Amplitude Coupling Computation**
- Modulation Index (Tort et al., 2010, J Neurophysiol)
- Theta phase (4-8 Hz) x gamma amplitude (38-42 Hz)
- Computed at epoch level (full 20-40s blocks) for stability, then assigned to all constituent 2s windows
- PAC values: dimensionless MI units, range [6x10^-6, 7x10^-4], mean ~4.4x10^-5
- Explain that epoch-level PAC assigned to windows means windows from the same epoch share the same label — this is deliberate (stable labels) but creates a data ceiling for per-window prediction

**4.3 Static PAC Estimation: EEGNet**
- EEGNet architecture (Lawhern et al., 2018): 1,457 parameters
- Input: (batch, 1, 7, 500) — 7 channels, 2s at 250 Hz
- Block 1: temporal conv (F1=8 filters, kernel=64) + depthwise spatial conv
- Block 2: separable conv (F2=16 filters, kernel=16)
- FC regression head: output (batch, 1) predicted PAC
- Training: MSE loss, Adam optimizer, ReduceLROnPlateau, gradient clipping (max_norm=1.0), early stopping
- Z-score normalization of PAC targets (mean/std saved in checkpoint)
- Best epoch: 53
- Test R-squared: 0.287

**4.4 Feature Engineering for Temporal Prediction**
- 73-dimensional causal feature vector per timestep:
  - 61 spectral features: 5 frequency bands (delta, theta, alpha, beta, gamma) x 7 channels = 35 band powers + 26 cross-channel coherence features
  - 7 PAC-derived features: rolling statistics of PAC history
  - 5 stimulation context features: current stim state, time since last stim change, etc.
- Z-score normalization computed only on training set, applied to val/test
- No future leakage: all features computed from current and past windows only

**4.5 Temporal PAC Forecasting: MultiscaleCausalTCN**
- Architecture: MultiscaleCausalTCN, 31,043 parameters
- Causal depthwise-separable conv blocks with dilations [1, 2, 4, 8]
- GroupNorm (not BatchNorm) for cross-subject stability
- Attention pooling over temporal dimension
- Dual-head output: future PAC prediction + delta-PAC prediction (multi-task)
- Input: 20-step lookback window (20 seconds), 73 features per step
- Prediction horizon: 5 seconds ahead
- Target smoothing: ts=1 (raw PAC) for deployed model
- Training: Huber loss + multi-task delta/consistency penalty
- ReduceLROnPlateau, early stopping (patience=20)
- Training data: 11,160 sequences (24 subjects)

**4.6 Closed-Loop Controller Design**
- Describe the 4 primary controllers + 2 reference controllers:
  1. Fixed Schedule: 40s ON / 20s OFF (mimics clinical protocol)
  2. Reactive Threshold: z-score of current PAC, threshold at +/-0.5
  3. TCN Predictive: uses predicted PAC 5s ahead for proactive decisions
  4. Hybrid TCN+Reactive: blends predictive and reactive signals
  5. PI Controller: proportional-integral feedback control
  6. Alignment Oracle: perfect hindsight (theoretical upper bound)
- PersonalizationModule: 30-second rolling baseline, z-score normalization
- Decision logic: z < -0.5 -> STIMULATE, z > +0.5 -> REST, else MAINTAIN
- 5-second hysteresis to prevent rapid switching

**4.7 Validation Protocol**
- Offline counterfactual replay on all 35 subjects' real EEG
- Critical detail: "For validation, ground-truth PAC labels were used as TCN input, isolating the TCN's predictive contribution from EEGNet estimation error."
- Use the phrase "offline counterfactual replay" explicitly
- Explain that decisions are computed on real EEG but the system cannot observe the brain's response to those decisions (because they are counterfactual)
- Do NOT say "we delivered stimulation" — say "we computed stimulation decisions"

**4.8 Statistical Analysis**
- All comparisons: Wilcoxon signed-rank test (paired, N=35 subjects)
- Effect sizes: Hedges' g with 95% confidence intervals
- Metrics defined:
  - Alignment: (Low-PAC Stim Rate + High-PAC Rest Rate) / 2
  - Low-PAC Stim: fraction of below-median PAC windows receiving stimulation
  - High-PAC Rest: fraction of above-median PAC windows where controller rests
  - PAC Gap: mean PAC during rest minus mean PAC during stim (positive = correctly targeting low-PAC)

**Critical accuracy requirements:**
- TCN patience=20 (NOT 10)
- EEGNet loss=MSE (NOT Huber)
- Best epoch=53
- PAC units: dimensionless MI (Tort 2010), NEVER use "uV-squared" for PAC values
- Validation is offline counterfactual replay, NOT live streaming

**5.3 The R-squared = 0.287 Data Ceiling: Interpretation and Implications**
- Frame as a scientific finding, not a failure
- The ceiling exists because: epoch-level PAC labels assigned to 2s windows = label noise. The instantaneous EEG of a 2s window cannot fully determine the PAC computed over a 20-40s epoch
- When a 135-parameter Ridge model matches a 1.1M-parameter ViT, the bottleneck is data, not model capacity
- This is analogous to the Bayes error rate: there is a fundamental limit to what can be extracted from this signal at this temporal resolution

**5.4 Motivation for Temporal Prediction Pivot**
- The ceiling motivates looking at PAC dynamics over time rather than instantaneous prediction
- If future PAC can be predicted from the sequence of recent PAC values + spectral features, proactive control becomes possible
- The relevant signal is how PAC evolves over 5-10 seconds, not what a single 2s window says about current PAC
- This directly leads to the MultiscaleCausalTCN described in Methods
