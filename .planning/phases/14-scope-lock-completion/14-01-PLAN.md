Create fit_simulator_params.py at the repo root. The script:

1. Loads all three splits from data/processed/multiscale_temporal_lb20_hz5_ts1/ (train_multiscale.npz, val_multiscale.npz, test_multiscale.npz).

2. Reconstructs per-subject PAC time series by grouping sequences by subject ID and sorting by end_idx. Each sequence's `last_pac` value gives the PAC at the end of its lookback window. Chain these together per subject to get a PAC trajectory.

3. Also extract the stim_state from each sequence's last timestep (x_seq[:, -1, 70] — feature index for stim_state is 70 in the 73-feature vector, confirmed from feature_names). This gives the stim/rest label for each time point.

4. For each subject, fit τ values:
   - For each consecutive pair (pac_t, pac_t1) where action == STIMULATE (stim_state == 1):
     - target = per-subject 90th percentile PAC (robust max)
     - τ_candidate = (pac_t1 - pac_t) / (target - pac_t) if (target - pac_t) > 1e-8
     - Keep only candidates where 0 < τ_candidate <= 1
   - For each pair where action == REST (stim_state == 0):
     - target = per-subject 10th percentile PAC (robust min)
     - τ_candidate = (pac_t1 - pac_t) / (target - pac_t) if (pac_t - target) > 1e-8
     - Keep only candidates where 0 < τ_candidate <= 1
   - Record median τ_rise and τ_decay for the subject if >= 5 valid candidates each

5. Aggregate across subjects: report population median ± IQR for τ_rise and τ_decay.

6. Print a results table:
   ```
   === Simulator Tau Parameter Fitting ===
   Dataset: multiscale_temporal_lb20_hz5_ts1 (N=35 subjects)

   Population estimates:
     tau_rise:  {median:.4f} (IQR: {q25:.4f}-{q75:.4f}, n={n} subjects)
     tau_decay: {median:.4f} (IQR: {q25:.4f}-{q75:.4f}, n={n} subjects)

   Comparison with heuristic defaults:
     tau_rise:  fitted={X:.4f}  vs  heuristic=0.15  (ratio: {X/0.15:.2f}x)
     tau_decay: fitted={Y:.4f}  vs  heuristic=0.10  (ratio: {Y/0.10:.2f}x)

   Time constants (T = -1/ln(1-tau)):
     tau_rise  = {X:.4f} → T={rise_tc:.1f}s  (heuristic: 6.2s)
     tau_decay = {Y:.4f} → T={decay_tc:.1f}s  (heuristic: 9.5s)
   ```

7. Save results/simulator_tau_fit.json with keys:
   - tau_rise_median, tau_rise_q25, tau_rise_q75, tau_rise_n_subjects
   - tau_decay_median, tau_decay_q25, tau_decay_q75, tau_decay_n_subjects
   - heuristic_tau_rise (0.15), heuristic_tau_decay (0.10)
   - per_subject: list of {subject, tau_rise, tau_decay, n_rise_transitions, n_decay_transitions}
   - fit_method: "exponential_approach_median_per_subject"
   - data_source: "multiscale_temporal_lb20_hz5_ts1"

Use argparse with:

  --output    (default: results/simulator_tau_fit.json)
  --verbose   (flag, prints per-subject breakdown)

Follow project conventions: Path(__file__).resolve() for root, numpy/json only (no sklearn), type hints on all public functions, PEP 8, module docstring citing the SIMULATOR_DEFENSE.md analysis.
