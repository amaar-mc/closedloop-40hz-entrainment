       - Build SOS-format Butterworth bandpass filters for theta (4-8 Hz) and gamma (38-42 Hz) at init time using `scipy.signal.butter(..., output='sos')`

         f. Compute cross-channel stats (theta_power_mean, theta_power_std, gamma_power_mean, gamma_power_std, theta_gamma_ratio_mean) — 5 features
         g. Concatenate in exact same order as offline: theta + gamma + alpha + beta + ratio + pac_flat + cross_channel
       - `reset()` method: zero all filter states
       - Property `n_features -> int` returning `8 * self.n_channels + 5`
