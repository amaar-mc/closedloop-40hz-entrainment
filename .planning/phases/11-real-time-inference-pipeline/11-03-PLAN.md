  <action>
    1. Create `scripts/demo_streaming.py` with argparse CLI:
       - `--steps N` (default 30): number of 2-second inference steps to run
       - `--source {simulated,muse}` (default simulated): which EEG adapter to use
       - `--model {tcn}` (default tcn): which TemporalModel from registry (extensible for Phase 12)
       - `--n-channels N` (default 4): number of EEG channels
       - `--device {cpu,mps,cuda}` (default: auto-detect)

    2. Inference loop structure:
       a. Create `SimulatedEEGAdapter(n_channels=args.n_channels)` or `RealEEGAdapter()` based on --source
       b. Create `StreamingFeatureExtractor(n_channels=args.n_channels)`
       c. Load `ModelRegistry` via `build_default_registry()` and get model by `args.model`
       d. Load EEGNet 4-channel model from `models/muse_4ch/best_eegnet_4ch.pth` for static PAC prediction:
          - `model = EEGNet(n_channels=args.n_channels, n_samples=500)`
          - Load checkpoint, set eval mode
          - Denormalize PAC using checkpoint's mean/std if present
       e. Track stim_state, time_since_switch, stim_frac_recent across loop iterations
       f. Each step:
          - `window = adapter.get_window()` — (4, 500)
          - `features = extractor.process_window(window)` — (37,)
          - EEGNet PAC: `pac = eegnet(window_tensor).item()` (denormalized)
          - TCN prediction: `prediction = model.step(features, pac, stim_state, time_since_switch, stim_frac_recent)`
          - Decision: use z-score from PAC if baseline ready (build a simple PersonalizationModule instance)
          - Print formatted line: step number, PAC value, future PAC (or "warmup"), z-score (or "calibrating"), decision (STIMULATE/REST)
       g. Print summary at end: total steps, warmup steps, % stimulation, mean PAC

    3. Use `sys.path.insert(0, str(REPO_ROOT))` and `sys.path.insert(0, str(REPO_ROOT / "src"))` at the top for imports. Use `Path(__file__).resolve().parent.parent` for REPO_ROOT.

    4. Create `tests/test_simulated_session.py`:
       - Runs 25 steps of the demo in simulated mode programmatically (not via subprocess)
       - Imports the same components directly
       - Verifies:
         a. Each get_window() returns (4, 500) float32
         b. Each process_window() returns (37,) float32
         c. EEGNet produces a scalar PAC value
         d. TCN model returns None for first lookback-1 steps, then dict with "future_pac" key
         e. No exceptions raised during the 25-step loop
       - Print [PASS] / [FAIL] per check, exit 1 on failure
       - Uses `time.sleep(0.1)` between steps instead of 2.0 to run fast (override adapter timing)

    CRITICAL: The `ClosedLoopController` from `src/controller.py` expects 7-channel input and loads its own EEGNet internally. For the 4-channel demo, do NOT use ClosedLoopController directly — instead manually instantiate EEGNet(n_channels=4) and PersonalizationModule separately. The PredictiveLookAheadController already accepts a forecaster externally and does not load its own model, so it can be used if you pass a RealtimePACForecaster, but note its step() expects spectral_features as input (not raw EEG), which matches our pipeline.

    CRITICAL: EEGNet checkpoint may have z-score normalization stats (pac_mean, pac_std). Check for these keys and denormalize: `pac_raw = pac_z * pac_std + pac_mean`. If keys are missing, use raw output.
