## Decisions Made

- Used `scipy.spatial.distance.cdist` with `metric="chebyshev"` for sample entropy template matching — avoids nested Python loops, feasible over 500-sample windows at 11K+ windows per split.
- Feature block order: `[spectral | enhanced | PAC-derived | stim_ctx]` — enhanced features inserted immediately after spectral so the block has a clear positional identity in the 108-dim vector.
- Output NPZ keys kept identical to existing multiscale datasets (`x_seq`, `y_future`, `y_delta`, `last_pac`, `y_future_norm`, `y_delta_norm`, `subjects`, `start_idx`, `end_idx`, `target_idx`, `feature_names`) — Plan 02 training code runs with `--data-dir` unchanged.
- `improved_tcn/` established as a new top-level package rather than extending `temporal_multiscale/` — keeps the new capability isolated and avoids contaminating the existing audited pipeline.
