<objective>
Build enhanced time-domain feature extractor and create augmented multiscale datasets for both 7-channel and 4-channel configurations.

Purpose: The existing spectral features (Welch PSD bands, theta-gamma ratios, cross-channel stats) are purely frequency-domain. Adding Hjorth parameters (activity, mobility, complexity), sample entropy, and zero-crossing rate per channel captures time-domain dynamics like signal irregularity, morphological complexity, and transition rates that PSD misses. These features are well-established in EEG BCI literature and are cheap to compute.

Output: Enhanced datasets at data/processed/enhanced_multiscale_7ch/ (108 features) and data/processed/muse_4ch/enhanced_multiscale/ (69 features), ready for Plan 02 training.
</objective>

**improved_tcn/enhanced_features.py** — Pure feature extraction module:

1. `compute_hjorth_params(signal: np.ndarray) -> Tuple[float, float, float]`
   - Input: 1D signal array (500 samples)
   - Activity = np.var(signal)
   - First derivative: dx = np.diff(signal)
   - Mobility = np.std(dx) / (np.std(signal) + 1e-12)
   - Second derivative: ddx = np.diff(dx)
   - Complexity = (np.std(ddx) / (np.std(dx) + 1e-12)) / (mobility + 1e-12)
   - Returns (activity, mobility, complexity)

2. `compute_sample_entropy(signal: np.ndarray, m: int, r: float) -> float`
   - Implements approximate sample entropy (SampEn) with embedding dimension m=2 and tolerance r=0.2*std(signal).
   - If std < 1e-12 (flat signal), return 0.0.
   - Count template matches at lengths m and m+1 using Chebyshev distance.
   - Return -ln(B/A) where A = matches at m+1, B = matches at m. If B==0 or A==0, return 0.0.
   - IMPORTANT: Use vectorized pairwise distance computation (not nested python loops) for performance. The N=500 samples per window makes brute-force viable but loops over 11K+ windows require the inner computation to be fast. Use scipy.spatial.distance.cdist or numpy broadcasting.

3. `compute_zero_crossing_rate(signal: np.ndarray) -> float`
   - Count sign changes: np.sum(np.diff(np.sign(signal)) != 0) / len(signal)

4. `extract_enhanced_features(eeg_window: np.ndarray, fs: float) -> np.ndarray`
   - Input: eeg_window shape (n_channels, n_samples) — squeezed from (1, C, 500)
   - For each channel, compute: hjorth_activity, hjorth_mobility, hjorth_complexity, sample_entropy(m=2, r=0.2*std), zero_crossing_rate
   - Return flat array: (5 * n_channels,) — ordered channel-by-channel
   - Feature names: [f"{feat}_{ch}" for ch in range(n_channels) for feat in ["hjorth_activity", "hjorth_mobility", "hjorth_complexity", "sample_entropy", "zcr"]]

5. `extract_enhanced_features_batch(windows: np.ndarray) -> np.ndarray`
   - Input: windows shape (N, 1, C, 500)
   - Squeeze dim 1, loop over N, return (N, 5*C) array
   - Print progress every 1000 windows

6. Self-test block at bottom:

   - Verify output shape is (35,) for 7ch
   - Verify all values are finite (not NaN or inf)
   - Verify Hjorth activity > 0 for non-zero signal
