<objective>
Build and train the improved TCN architecture with temporal self-attention and multi-task auxiliary smoothing, then evaluate against Phase 12 baselines on both 7ch and 4ch datasets.

Purpose: The baseline TCN has only local receptive fields via dilated convolutions. Adding multi-head self-attention provides global temporal context — the model can learn which historical timesteps matter most. The auxiliary smoothed-PAC loss provides cleaner gradient signal during training, guiding the learned representation toward capturing the underlying PAC trend rather than raw noise. These are complementary improvements: attention improves architecture, smoothing improves training signal.

Output: Trained improved TCN checkpoints, results JSONs, and a comparison table showing R2 delta vs Phase 12 baselines.
</objective>

3. **temporal_self_attention** — NEW: Multi-head self-attention between TCN output and pooling.
   - After TCN: x is (B, H, T). Transpose to (B, T, H) for attention.

     - d_model=hidden (64)
     - nhead=n_attn_heads (4)

5. **Heads — THREE regression heads:**

Create improved_tcn/train_improved_tcn.py — training script adapted from temporal_multiscale/train_multiscale_tcn.py with the following key changes:

**1. SequenceDataset enhancement:**
Copy the SequenceDataset class. It already works with any NPZ that has x_seq, y_future_norm, y_delta_norm, last_pac. No changes needed.

BUT: Add a `y_smooth_norm` field. The smoothed target must be pre-computed in the dataset or computed on the fly.

Approach: Compute the smoothed target ON THE FLY during dataset loading. The smoothed target is a causal moving average of y_future with window=5:
```python
class EnhancedSequenceDataset(Dataset):
    def __init__(self, npz_path: Path, smooth_window: int = 5):
        d = np.load(npz_path, allow_pickle=True)
        self.x = torch.from_numpy(d["x_seq"]).float()
        self.y_future = torch.from_numpy(d["y_future_norm"]).float()
        self.y_delta = torch.from_numpy(d["y_delta_norm"]).float()
        self.last_pac = torch.from_numpy(d["last_pac"]).float()
        # Compute smoothed target from the normalized future PAC
        # This is a per-sample trailing average — we're smoothing the target labels
        y_f = d["y_future_norm"].astype(np.float64)
        y_smooth = np.convolve(y_f, np.ones(smooth_window)/smooth_window, mode='same')
        # Fix edges: for first smooth_window-1 samples, use expanding mean
        for i in range(smooth_window - 1):
            y_smooth[i] = y_f[:i+1].mean()
        self.y_smooth = torch.from_numpy(y_smooth).float()
```

IMPORTANT CORRECTION: The samples in the NPZ are NOT necessarily in temporal order (they're per-subject sequences interleaved). The smoothed target should be computed PER SUBJECT to avoid cross-subject bleed. However, the y_future values in the NPZ are already independent targets (each is a z-scored PAC value at a future timestep). The auxiliary smoothed target is simply a denoised version of these labels — we smooth over adjacent samples within the training batch, which is reasonable since adjacent samples from the same subject are adjacent in the NPZ (the dataset builder iterates per-subject contiguously).

Alternative simpler approach that avoids cross-subject issues: Smooth the y_future_norm values using a simple Gaussian kernel per-subject based on the subjects array in the NPZ. Group by subject, apply trailing causal mean within each subject, concatenate back.

**2. Multi-task training loop:**
```python
def train_one_epoch(..., lambda_smooth: float = 0.3, ...):
    # Standard forward pass
    out = model(x)  # {"future": ..., "delta": ..., "smooth": ...}

    loss_future = huber(out["future"], y_future)
    loss_delta = huber(out["delta"], y_delta)
    loss_smooth = huber(out["smooth"], y_smooth)  # NEW auxiliary loss

    # Consistency in raw PAC space (same as baseline)
    pred_future_raw = out["future"] * yf_std + yf_mean
    pred_delta_raw = out["delta"] * yd_std + yd_mean
    loss_consistency = torch.mean((pred_future_raw - (last_pac + pred_delta_raw)) ** 2)

    loss = loss_future + lambda_smooth * loss_smooth + lambda_delta * loss_delta + lambda_consistency * loss_consistency
```

The smoothed auxiliary head is trained with weight lambda_smooth=0.3 (default). It provides cleaner gradient signal through the shared backbone because the smoothed PAC target has less noise, pushing the representation toward learning the underlying trend.

**3. Evaluation — ONLY evaluates on the future head:**
The smooth head is auxiliary training-only. Evaluation uses out["future"] exclusively (same as baseline), so R2 comparisons are apples-to-apples.
