# CSEF 2026 Submission Archive

This directory preserves the completed CSEF 2026 application and presentation materials.

## Layout

- `abstract/`: submitted abstract and earlier versions.
- `forms/`: application forms.
- `package/`: final assembled submission PDF.
- `poster/`: poster source files, exports, and final PDFs.
- `presentation/`: talk scripts, interview preparation, slides, and supporting notes.
- `paper/`: CSEF research-paper drafts and generated PDFs.
- `lab_notebook/`: final notebook bundle and local generators.
- `flyer/`: facility-flyer source, PDF, and QR assets.
- `reference/`: CSEF-specific reference notes and judging material.
- `early_research/`: early DOCX research artifacts.

New conference applications belong under `paper/conferences/`, not in this archived CSEF package.
