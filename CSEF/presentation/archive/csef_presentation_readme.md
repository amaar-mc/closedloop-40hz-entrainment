## Archive

`archive/` contains everything that isn't actively used:
- `v1_scripts/` — old v1 scripts (60s opening, 1min POTY, 3min synopsis, 5min full, 2min core)
- `v1_interview/` — v1 master Q&A, computational deep dive, answer depth guide, superseded danger zones and medical deep dive
- `v1_guide/` — v1 behavioral guides (judge interaction, presentation flow, day-of checklist)
- `v1_reference/` — v1 numbers sheet, citations, CSEF rules cheatsheet, past winners analysis
- `v1_notebook/` — v1 notebook prep guide
- `v2_superseded/` — the earlier version of the boardwalk script and map that got replaced by the current boardwalk_3to4min.md

Nothing in `archive/` should be referenced during judging. Keep it around in case something needs to be reused later.
