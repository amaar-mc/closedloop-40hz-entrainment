Architecture Search: The R² = 0.287 Static Ceiling

Eight neural network architectures (1,457 to 1.1 M parameters) were tested for static PAC prediction from 2-second EEG snapshots. All converged to R² ≈ 0.287 — a data-imposed ceiling showing that epoch-level PAC cannot be recovered from instantaneous windows. This finding redirected the project toward temporal forecasting. The bottleneck was in the features, not the architecture.
