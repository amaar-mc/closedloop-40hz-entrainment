Conclusions

Key Findings

  • Eight architectures (1,457 to 1.1 M parameters) all converge to R² = 0.287 for static PAC prediction — a data-imposed ceiling proving the bottleneck is the feature representation, not the model.
  • Feature discovery: replacing 73 spectral features with 12 PAC+Stim features raised temporal test R² from −0.025 to 0.606 (5-seed mean; 4ch: 0.430). Feature selection mattered more than any architectural change.
  • The TCN maintains R² = 0.37–0.67 at 3–10 s horizons where persistence collapses to negative R², defining the operationally actionable regime for proactive neuromodulation.
  • The predictive controller achieves 72.1% alignment, 82.6% low-PAC targeting, and 91% of the theoretical oracle bound (all p < 0.001 vs. reactive; Hedges’ g = 1.31–4.47).
  • Universal benefit across all 35 subjects, including 6 held-out test subjects never seen during training.

Context

These results show that temporal PAC forecasting can drive proactive closed-loop control that outperforms both fixed-schedule and reactive protocols. No prior system has attempted PAC-specific temporal prediction for personalized gamma entrainment control. This work is a computational validation; live closed-loop trials are needed to confirm clinical translation.

Productization and Clinical Roadmap

  • Caregiver web application: deployed on Hugging Face Spaces (Streamlit); PAC monitoring, real-time stimulation control, personalized session tracking — the basis for a consumer neuromodulation device.
  • Phase 1 — Observational (now): collect real-world EEG + PAC data via app to characterize inter-session habituation patterns.
  • Phase 2 — Feasibility (12–18 mo): IRB-approved within-subject pilot (N = 5–10) comparing adaptive TCN vs. fixed-schedule 40 Hz stimulation.
  • Phase 3 — Comparative (3–5 yr): RCT in mild AD patients (N ≈ 20) comparing personalized adaptive vs. fixed protocol. Primary endpoint: maintained entrainment at 12-week follow-up.
  • Near-term technical: end-to-end validation (raw EEG → EEGNet → TCN → controller); per-subject online fine-tuning; 4-channel Muse-compatible deployment.
