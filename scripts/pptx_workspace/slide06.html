Closed-Loop Controller Design

  • Personalization: 30-second rolling baseline per subject; z-score = (PAC − μ) / σ
  • Decision logic: z < −0.5 → STIMULATE; z > +0.5 → REST; else MAINTAIN
  • 5-second hysteresis to prevent rapid state oscillation
  • Variants tested: Fixed Schedule, Reactive Threshold, TCN Predictive, Hybrid, PI Controller, Alignment Oracle

Validation Protocol

  • Offline counterfactual replay on all 35 subjects’ recorded EEG — not simulated brain dynamics
  • Ground-truth PAC labels used as TCN input to isolate forecaster’s contribution from EEGNet error
  • Metrics: Alignment = mean of Low-PAC Stim Rate and High-PAC Rest Rate; PAC Targeting Gap
  • Statistics: Wilcoxon signed-rank (paired, N = 35); Hedges’ g with 95% BCa bootstrap CIs (10,000 iterations)
