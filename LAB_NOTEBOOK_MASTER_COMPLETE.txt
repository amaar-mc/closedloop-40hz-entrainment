PAGE 2 - Entry: December 11, 2025
TOPIC: Deep Dive on Alzheimer's Disease Biology
--------------------------------------------------------------------------------

Spent today reading about AD pathology to understand what's actually going
wrong in the brain.

KEY FINDINGS:

1. THE AMYLOID CASCADE HYPOTHESIS
   - Aβ42 protein misfolds → forms plaques outside neurons
   - Plaques trigger inflammatory response
   - Tau protein inside neurons becomes hyperphosphorylated
   - Tau tangles form → neurons die
   - Synapses (connections) lost first, before cell death

2. AFFECTED BRAIN REGIONS (in order):
   - Entorhinal cortex (first, subtle memory issues)
   - Hippocampus (major memory loss)
   - Temporal lobe (language problems)
   - Parietal lobe (spatial navigation issues)
   - Frontal lobe (executive function decline)

3. GAMMA OSCILLATIONS (30-80 Hz brainwaves):
   - Generated by PING mechanism (Pyramidal-Interneuron Network Gamma)
   - Fast-spiking interneurons fire at gamma frequency
   - Synchronize pyramidal neuron activity
   - CRITICAL for memory encoding and retrieval
   - DISRUPTED in AD patients (reduced power, poor synchrony)

[DRAW DIAGRAM: Neuron circuit showing PING mechanism]
Draw: Pyramidal neuron (triangle) connected to interneuron (circle)
Show: Inhibitory feedback loop, label "40 Hz oscillation"

4. WHY GAMMA MATTERS:
   - Gamma synchrony = neurons firing together
   - "Neurons that fire together, wire together" (Hebbian learning)
   - Memory requires precise timing across brain regions
   - AD breaks this timing → memory fails

QUESTION: If gamma is disrupted in AD, can we restore it artificially?

This is where gamma entrainment comes in! (Need to read more tomorrow)

REFERENCES:
- Buzsáki & Wang (2012) "Mechanisms of Gamma Oscillations"
- Palop & Mucke (2016) "Network abnormalities and interneuron dysfunction in AD"

PAGE 14-16 - Entry: December 22, 2025
TOPIC: Literature Review - PAC Computation Methods
--------------------------------------------------------------------------------

Need to understand HOW to compute theta-gamma PAC from EEG.

Read Tort et al. (2010) "Measuring Phase-Amplitude Coupling Between Neuronal
Oscillations of Different Frequencies"

MAIN PAC METHODS:

1. MODULATION INDEX (MI) - Tort method
   - Extract theta phase (4-8 Hz) using Hilbert transform
   - Extract gamma amplitude envelope (30-80 Hz) using Hilbert
   - Bin theta phase into N bins (typically 18 bins, 20° each)
   - Average gamma amplitude in each phase bin
   - Compute KL-divergence of distribution from uniform
   - MI = 0 (no coupling) to 1 (perfect coupling)

2. MEAN VECTOR LENGTH (MVL)
   - Gamma amplitude as "height"
   - Theta phase as "angle"
   - Compute mean vector in polar coordinates
   - MVL = length of mean vector

3. GENERAL LINEAR MODEL (GLM)
   - Regress gamma amplitude ~ sin(theta) + cos(theta)
   - R² as coupling strength

DECISION: Use MODULATION INDEX (Tort method)
Reasons:
- Most widely cited in literature
- Insensitive to amplitude fluctuations
- Interpretable scale (0-1)
- Used in AD studies

[DRAW DIAGRAM: PAC computation visualization]
Top plot: Theta oscillation (4-8 Hz sine wave)
Middle plot: Gamma amplitude envelope (high-freq envelope)
Bottom plot: Circular histogram showing gamma amp in each theta phase bin
Show strong coupling: peak at 180° (trough of theta)

IMPLEMENTATION PLAN:
- Use MNE-Python for data loading
- Use scipy.signal.hilbert for phase/amplitude extraction
- Bandpass filters:
  - Theta: 4-8 Hz (5th order Butterworth)
  - Gamma: 38-42 Hz (narrow band around 40 Hz stim frequency)
- 18 phase bins
- KL divergence formula: Σ P(j) * log[P(j) / U(j)]
  where P = observed distribution, U = uniform

CONCERNS:
- PAC sensitive to filter settings (need to be careful)
- Surrogate testing needed to verify statistical significance?
- Computational cost if doing this in real-time

--------------------------------------------------------------------------------

Now that I know WHAT to predict (PAC), need to decide HOW (which ML model).

INPUT: EEG window (7 channels × 500 timepoints = 2 seconds @ 250 Hz)
OUTPUT: Predicted PAC value (scalar, 0-1 range)
TASK: Regression (not classification)

ARCHITECTURE OPTIONS CONSIDERED:

1. TRADITIONAL ML:
   Feature engineering → classical model
   - Extract features: PSD in bands, statistical moments, hjorth parameters
   - Model: Random Forest, XGBoost, Support Vector Regression
   - Pros: Fast, interpretable, less data needed
   - Cons: Manual feature engineering, might miss patterns

2. CNN (Convolutional Neural Network):
   - Conv layers learn spatial (electrodes) and temporal patterns
   - Example: EEGNet (Lawhern et al. 2018) - designed for EEG
   - Pros: End-to-end learning, proven for EEG
   - Cons: Need more data, less interpretable

3. RNN/LSTM (Recurrent Neural Network):
   - Sequential processing of time series
   - Pros: Natural for temporal data
   - Cons: Slow to train, vanishing gradients

4. TRANSFORMER:
   - Self-attention mechanism for temporal dependencies
   - Pros: State-of-art for sequences, parallel training
   - Cons: Huge data requirements, very slow

5. GRAPH NEURAL NETWORK:
   - Treat electrodes as nodes, learn spatial relationships
   - GAT (Graph Attention Network) - learns electrode importance
   - Pros: Incorporates brain topology
   - Cons: Complex, might overfit small dataset

6. HYBRID: GAT + TRANSFORMER
   - GAT for spatial (electrode relationships)
   - Transformer for temporal (time dependencies)
   - Pros: Theoretically best of both worlds
   - Cons: Most complex, most parameters, highest overfit risk

PAGE 19-20 - Entry: December 30, 2025
TOPIC: Control Strategy & MPC Formulation
--------------------------------------------------------------------------------

Even if I can predict PAC, how do I DECIDE when to stimulate?

CONTROL STRATEGIES TO COMPARE:

1. FIXED SCHEDULE (baseline):
   - ON for 40 seconds, OFF for 20 seconds
   - Repeat cycle
   - Current standard in literature

2. REACTIVE THRESHOLD:
   - If current PAC < threshold → stimulate
   - If current PAC > threshold → rest
   - Simple feedback, no prediction

3. PREDICTIVE MPC (my approach):
   - Predict PAC at t+5 seconds using EEG at time t
   - If predicted PAC < threshold → stimulate now
   - If predicted PAC > threshold → rest now
   - Uses future prediction for smarter decisions

4. ORACLE (theoretical upper bound):
   - Knows true future PAC (cheating)
   - Optimal decisions
   - Impossible in reality, but useful for benchmarking

[DRAW DIAGRAM: Control strategy comparison timeline]
Time axis with 4 rows:
Row 1 (Fixed): ON-OFF-ON-OFF regular pattern
Row 2 (Reactive): Irregular ON/OFF based on current PAC
Row 3 (Predictive): Irregular ON/OFF based on predicted PAC
Row 4 (Oracle): Optimal ON/OFF based on true future PAC

MPC (MODEL PREDICTIVE CONTROL) FORMULATION:

At each timestep t:
1. Measure EEG window [t-2s, t]
2. Predict PAC at time t+Δ (prediction horizon Δ = 5-10 seconds)
3. Decision rule:
   - If PAC_pred < threshold_low → Action = STIMULATE
   - If PAC_pred > threshold_high → Action = REST
   - Else → Action = HOLD (maintain current state)
4. Apply action for next Δ seconds
5. Repeat

THRESHOLDS: How to set?
- Personalized to each subject (not global)
- Use z-scores relative to rolling baseline
- Example: threshold_low = -0.5σ, threshold_high = +0.5σ

HYSTERESIS: To prevent rapid switching (ON-OFF-ON-OFF chatter)
- Require state to hold for minimum 5 seconds before switching
- Smooths control, more realistic for clinical use

METRICS TO COMPARE STRATEGIES:
1. Mean PAC achieved
2. Variance of PAC (stability)
3. Total stimulation time (efficiency)
4. Number of state switches (practicality)

HYPOTHESIS REFINEMENT:
Predictive MPC will outperform fixed schedule and reactive control in mean
PAC achieved while using less total stimulation time.

```python
import h5py
import numpy as np
import mne

def load_set_file_hdf5(filepath):
    """Load MATLAB v7.3 .set file"""
    with h5py.File(filepath, 'r') as f:
        # Inspect structure
        print("Keys in file:", list(f.keys()))

        # Navigate to EEG structure
        eeg_struct = f['EEG']

        # Extract data array (shape: channels × timepoints)
        data_ref = eeg_struct['data']
        data = data_ref[:]  # Load into memory

        # Extract sampling rate
        srate_ref = eeg_struct['srate']
        srate = float(srate_ref[0, 0])

        # Extract channel names
        chanlocs = eeg_struct['chanlocs']
        n_channels = data.shape[0]
        ch_names = []
        for i in range(n_channels):
            label_ref = chanlocs['labels'][i, 0]
            label = ''.join(chr(c) for c in f[label_ref][:])
            ch_names.append(label)

        # Create MNE Info object
        info = mne.create_info(ch_names=ch_names,
                                sfreq=srate,
                                ch_types='eeg')

        # Create RawArray
        raw = mne.io.RawArray(data * 1e-6, info)  # Convert µV to V

        return raw
```

```python
from scipy.signal import hilbert, butter, filtfilt

def compute_pac_tort(eeg_window, sfreq=500):
    """
    Compute theta-gamma PAC using Tort Modulation Index
    eeg_window: array (n_channels, n_samples)
    """
    # Average across channels (for simplicity)
    signal = eeg_window.mean(axis=0)

    # Bandpass filters
    theta_band = [4, 8]
    gamma_band = [38, 42]  # Narrow band around 40 Hz stim

    # Extract theta phase
    b, a = butter(3, np.array(theta_band)/(sfreq/2), 'bandpass')
    theta_filt = filtfilt(b, a, signal)
    theta_phase = np.angle(hilbert(theta_filt))

    # Extract gamma amplitude
    b, a = butter(3, np.array(gamma_band)/(sfreq/2), 'bandpass')
    gamma_filt = filtfilt(b, a, signal)
    gamma_amp = np.abs(hilbert(gamma_filt))

    # Bin by phase (18 bins)
    n_bins = 18
    phase_bins = np.linspace(-np.pi, np.pi, n_bins+1)
    mean_amp_per_bin = np.zeros(n_bins)

    for i in range(n_bins):
        in_bin = (theta_phase >= phase_bins[i]) & (theta_phase < phase_bins[i+1])
        mean_amp_per_bin[i] = gamma_amp[in_bin].mean()

    # Normalize to probability distribution
    p = mean_amp_per_bin / mean_amp_per_bin.sum()

    # Uniform distribution
    u = np.ones(n_bins) / n_bins

    # KL divergence (Modulation Index)
    mi = np.sum(p * np.log(p / u))
    mi_norm = mi / np.log(n_bins)  # Normalize to [0, 1]

    return mi_norm
```

PAGE 34-36 - Entry: January 12, 2026
TOPIC: Preprocessing Pipeline Implementation
--------------------------------------------------------------------------------

Standard EEG preprocessing steps to clean data before ML model.

PIPELINE:

1. RESAMPLING: 500 Hz → 250 Hz
   - Original: 500 Hz (overkill for <100 Hz signals)
   - Target: 250 Hz (sufficient for 0-80 Hz content)
   - Method: scipy.signal.decimate with lowpass
   - Benefit: 50% reduction in data size, faster processing

2. BANDPASS FILTER: 0.5 - 80 Hz
   - High-pass 0.5 Hz: Remove slow drifts
   - Low-pass 80 Hz: Remove high-frequency noise, keep theta+gamma
   - Order: 5th order Butterworth
   - Zero-phase: filtfilt (forward-backward to avoid phase shift)

[DRAW DIAGRAM: Filter frequency response]
X-axis: Frequency (Hz), log scale
Y-axis: Gain (dB)
Show: Passband flat from 0.5-80 Hz, rolloff outside

3. NOTCH FILTER: 60 Hz (and harmonics 120 Hz)
   - Remove power line noise (US standard is 60 Hz)
   - Q-factor: 30 (narrow notch)
   - Also notch 120 Hz harmonic

4. COMMON AVERAGE REFERENCE (CAR):
   - Each channel: subtract mean of all channels at each timepoint
   - Removes common-mode noise (e.g., reference drift)
   - Formula: EEG_i(t) = EEG_i(t) - mean_j(EEG_j(t))

5. ARTIFACT REJECTION: Amplitude threshold
   - If any channel exceeds ±100 µV: mark window as bad
   - Rationale: Eye blinks, muscle artifacts typically >100 µV
   - Clean EEG usually <50 µV
   - Will lose some data but improves quality

IMPLEMENTATION CODE:
```python
from scipy.signal import butter, filtfilt, iirnotch, decimate

def preprocess_eeg(raw, channels=['Fp1','Fp2','F7','F3','Fz','F4','F8']):
    # Pick channels
    raw_subset = raw.copy().pick_channels(channels)

    # Resample 500→250 Hz
    raw_subset.resample(250)

    # Bandpass 0.5-80 Hz
    raw_subset.filter(l_freq=0.5, h_freq=80, method='iir',
                       iir_params={'order': 5, 'ftype': 'butter'})

    # Notch 60 Hz
    raw_subset.notch_filter(freqs=[60, 120], method='iir')

    # CAR
    raw_subset.set_eeg_reference(ref_channels='average')

    # Get data
    data = raw_subset.get_data()  # (7 channels, n_samples)

    # Artifact rejection
    threshold = 100e-6  # 100 µV in Volts
    bad_mask = np.any(np.abs(data) > threshold, axis=0)

    return data, bad_mask
```

TOPIC: Windowing Strategy & Label Generation
--------------------------------------------------------------------------------

Need to split continuous EEG into windows for model training.

WINDOWING PARAMETERS:

Window duration: 2 seconds
- 2 sec × 250 Hz = 500 samples per window
- Long enough to capture multiple theta cycles (4-8 Hz → 0.125-0.25 sec period)
- Short enough for ~180 windows per subject

Hop size: 1 second (50% overlap)
- Overlap increases effective sample size
- Smooth transitions (prevents edge effects)
- 360 sec recording → ~179 windows per subject

Total windows: 35 subjects × 179 = ~6,265 windows

[DRAW DIAGRAM: Sliding window illustration]
Timeline: |----2s----|
              |----2s----|
                  |----2s----|
          ← 1s hop →

LABEL GENERATION: PAC for each window

For each window:
1. Extract 7-channel EEG (7 × 500)
2. Compute theta-gamma PAC using Tort MI method
3. PAC = scalar value (0-1 range, typically 0.0005-0.003)
4. This becomes the LABEL (y) for that window
5. EEG window becomes the INPUT (X)

PREDICTION TARGET: What PAC to predict?

Option A: Current window PAC (t0)
- Input: EEG[t0-2s, t0]
- Output: PAC[t0-2s, t0]
- Problem: Not useful for control (need future prediction!)

Option B: Next window PAC (t0 + hop)
- Input: EEG[t0-2s, t0]
- Output: PAC[t0+1s, t0+3s]
- Prediction horizon: 1-3 seconds ahead
- More useful for control

Option C: Far-future PAC (t0 + 10s)
- Input: EEG[t0-2s, t0]
- Output: PAC[t0+10s, t0+12s]
- Prediction horizon: 10-12 seconds ahead
- Most useful but HARDEST to learn

DECISION: Start with Option B (next window, 1-3s ahead)
- Reasonable prediction horizon for control
- Not too difficult (signals are autocorrelated)
- Can extend to farther horizon later if needed

```python
def create_windowed_dataset(subject_ids, window_sec=2, hop_sec=1):
    all_X = []
    all_y = []

    for sub_id in subject_ids:
        # Load and preprocess
        raw = load_subject(sub_id)
        data, bad_mask = preprocess_eeg(raw)

        # Sliding window
        n_samples = window_sec * 250
        hop_samples = hop_sec * 250

        for i in range(0, data.shape[1] - 2*n_samples, hop_samples):
            # Input window
            window_in = data[:, i:i+n_samples]

            # Target window (next window)
            window_out = data[:, i+hop_samples:i+hop_samples+n_samples]

            # Skip if artifact
            if bad_mask[i:i+n_samples].any() or bad_mask[i+hop_samples:i+hop_samples+n_samples].any():
                continue

            # Compute PAC for target window
            pac = compute_pac_tort(window_out)

            all_X.append(window_in)
            all_y.append(pac)

    X = np.array(all_X)  # (n_windows, 7, 500)
    y = np.array(all_y)  # (n_windows,)

    return X, y
```

PAGE 40-43 - Entry: January 17, 2026
TOPIC: GAT-Transformer Architecture Design
--------------------------------------------------------------------------------

Implementing Graph Attention Network + Transformer hybrid.

RATIONALE:
- GAT: Learn spatial relationships between electrodes
- Transformer: Learn temporal dependencies across time

ARCHITECTURE DETAILS:

INPUT: (batch, 7 channels, 500 timepoints)

LAYER 1: Graph Attention Network (Spatial)
- Treat 7 channels as graph nodes
- Fully connected graph (all-to-all edges initially)
- 4 attention heads
- Hidden dimension: 128 per head
- Output: (batch, 7, 512) where 512 = 128 × 4 heads

[DRAW DIAGRAM: GAT layer]
7 circles (nodes) representing channels: Fp1, Fp2, F7, F3, Fz, F4, F8
Arrows between all pairs showing attention
Each arrow has learned weight (thickness shows attention strength)

Attention mechanism:
α_ij = softmax(LeakyReLU(a^T [W h_i || W h_j]))

Where:
- h_i = features of node i (channel i)
- W = learned weight matrix
- a = attention vector
- || = concatenation
- α_ij = attention weight from node i to node j

LAYER 2: Flatten spatial dimension
- Take mean across 7 nodes (global average pooling)
- Output: (batch, 512, 500)

LAYER 3: Positional Encoding
- Add learned positional embeddings to represent time order
- Each of 500 timepoints gets unique embedding vector
- Output: (batch, 500, 512)

LAYER 4: Transformer Encoder
- 3 encoder layers
- 8 attention heads per layer
- Dimension: 512
- Feed-forward: 2048 hidden units
- Dropout: 0.3

[DRAW DIAGRAM: Transformer architecture]
Stack of 3 identical blocks, each containing:
- Multi-head self-attention (8 heads)
- Add & Norm (residual + layer norm)
- Feed-forward network (512→2048→512)
- Add & Norm

LAYER 5: Pooling
- Global average pooling across time dimension
- Output: (batch, 512)

LAYER 6: Regression head
- Fully connected: 512 → 1
- Output: Predicted PAC (scalar)

TOTAL PARAMETERS:
- GAT: ~230K parameters
- Positional encoding: ~256K
- Transformer: ~8.5M parameters
- FC head: 513 parameters
- TOTAL: ~9 million parameters

[DRAW FLOWCHART: Data flow through architecture]
(batch,7,500) → GAT → (batch,7,512) → Pool → (batch,512,500) →
PosEnc → (batch,500,512) → Transformer → (batch,500,512) →
Pool → (batch,512) → FC → (batch,1)

IMPLEMENTATION (PyTorch):
```python
import torch
import torch.nn as nn
from torch_geometric.nn import GATConv

class GATTransformer(nn.Module):
    def __init__(self):
        super().__init__()

        # GAT layer
        self.gat = GATConv(in_channels=500,
                           out_channels=128,
                           heads=4,
                           concat=True)

        # Positional encoding
        self.pos_encoding = nn.Parameter(torch.randn(1, 500, 512))

        # Transformer
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=512,
            nhead=8,
            dim_feedforward=2048,
            dropout=0.3
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=3)

        # Regression head
        self.fc = nn.Linear(512, 1)

    def forward(self, x):
        # x: (batch, 7, 500)
        batch_size = x.shape[0]

        # Prepare for GAT (needs edge_index for graph)
        # Fully connected: all 7 nodes connected
        edge_index = torch.combinations(torch.arange(7), r=2).T
        edge_index = torch.cat([edge_index, edge_index.flip(0)], dim=1)

        # Apply GAT per batch
        gat_out = []
        for i in range(batch_size):
            out = self.gat(x[i].T, edge_index)  # (500, 512)
            gat_out.append(out)
        gat_out = torch.stack(gat_out)  # (batch, 500, 512)

        # Add positional encoding
        x = gat_out + self.pos_encoding

        # Transformer expects (seq, batch, features)
        x = x.permute(1, 0, 2)  # (500, batch, 512)
        x = self.transformer(x)
        x = x.permute(1, 0, 2)  # (batch, 500, 512)

        # Global average pooling
        x = x.mean(dim=1)  # (batch, 512)

        # Regression
        out = self.fc(x)  # (batch, 1)

        return out
```

TOPIC: EEGNet Architecture - Simplification
--------------------------------------------------------------------------------

Switching to EEGNet (Lawhern et al. 2018).

WHY EEGNET?
- Designed specifically for EEG-based BCIs
- Tiny: ~2,000 parameters (4,500× smaller than GAT-Transformer!)
- Depthwise-separable convolutions = parameter-efficient
- Proven track record on small EEG datasets
- Fast training (minutes instead of hours)

EEGNET ARCHITECTURE:

Block 1: Temporal + Spatial feature extraction
```
Input: (batch, 1, C, T) where C=7 channels, T=500 samples
  ↓
Conv2D: (1 → F1, kernel=(1, 64), padding='same')
  - Temporal convolution along time dimension
  - F1 = 8 filters
  - Learns 64-sample (~0.25s) temporal patterns
  ↓
BatchNorm2D
  ↓
DepthwiseConv2D: (F1 → F1*D, kernel=(C, 1), groups=F1)
  - Spatial convolution across channels
  - D = 2 (depth multiplier)
  - Output: F1*D = 16 feature maps
  - Each temporal filter gets own spatial filter
  ↓
BatchNorm2D
  ↓
ELU activation
  ↓
AvgPool2D: (1, 4)
  - Temporal downsampling by 4
  - 500 → 125 samples
  ↓
Dropout: p=0.5
  ↓
Output Block 1: (batch, 16, 1, 125)
```

[DRAW DIAGRAM: Block 1 operations]
Show input as 7 rows (channels) × 500 columns (time)
Temporal conv: Horizontal filters across time
Depthwise: Vertical filters across channels
Pooling: Compression along time axis

Block 2: Separable convolution
```
Input: (batch, 16, 1, 125)
  ↓
SeparableConv2D:
  Depthwise: (16 → 16, kernel=(1, 16), groups=16)
  Pointwise: (16 → F2, kernel=(1, 1))
  - F2 = 16
  - Separable = depthwise followed by pointwise
  - Learns temporal patterns in feature space
  ↓
BatchNorm2D
  ↓
ELU activation
  ↓
AvgPool2D: (1, 8)
  - 125 → 15 samples
  ↓
Dropout: p=0.5
  ↓
Output Block 2: (batch, 16, 1, 15)
```

Regression Head:
```
Input: (batch, 16, 1, 15)
  ↓
Flatten: (batch, 240)
  ↓
Linear: (240 → 1)
  ↓
Output: (batch, 1) - Predicted PAC
```

PARAMETER COUNT:
- Block 1 temporal conv: 1*8*1*64 = 512
- Block 1 depthwise: 8*2*7*1 = 112
- Block 2 separable: 16*1*16 + 16*16 = 512
- FC layer: 240*1 + 1 = 241
- BatchNorm params: ~200
- TOTAL: ~1,577 parameters

Compare to GAT-Transformer: 9,000,000 vs 1,577 = 5,700× reduction!

IMPLEMENTATION (PyTorch):
```python
import torch.nn as nn

class EEGNet(nn.Module):
    def __init__(self, n_channels=7, n_samples=500,
                 F1=8, D=2, F2=16, dropout=0.5):
        super().__init__()

        # Block 1
        self.conv1 = nn.Conv2d(1, F1, (1, 64), padding=(0, 32))
        self.batchnorm1 = nn.BatchNorm2d(F1)
        self.depthwise = nn.Conv2d(F1, F1*D, (n_channels, 1), groups=F1)
        self.batchnorm2 = nn.BatchNorm2d(F1*D)
        self.activation1 = nn.ELU()
        self.pool1 = nn.AvgPool2d((1, 4))
        self.dropout1 = nn.Dropout(dropout)

        # Block 2
        self.separable = nn.Sequential(
            nn.Conv2d(F1*D, F1*D, (1, 16), padding=(0, 8), groups=F1*D),
            nn.Conv2d(F1*D, F2, (1, 1))
        )
        self.batchnorm3 = nn.BatchNorm2d(F2)
        self.activation2 = nn.ELU()
        self.pool2 = nn.AvgPool2d((1, 8))
        self.dropout2 = nn.Dropout(dropout)

        # Calculate flattened size
        # After conv1: (1, F1, 7, 500)
        # After depthwise: (1, F1*D, 1, 500)
        # After pool1: (1, F1*D, 1, 125)
        # After separable: (1, F2, 1, 125)
        # After pool2: (1, F2, 1, 15)
        flatten_size = F2 * 1 * 15

        # Regression head
        self.fc = nn.Linear(flatten_size, 1)

    def forward(self, x):
        # x: (batch, 7, 500)

        # Add channel dim: (batch, 1, 7, 500)
        x = x.unsqueeze(1)

        # Block 1
        x = self.conv1(x)
        x = self.batchnorm1(x)
        x = self.depthwise(x)
        x = self.batchnorm2(x)
        x = self.activation1(x)
        x = self.pool1(x)
        x = self.dropout1(x)

        # Block 2
        x = self.separable(x)
        x = self.batchnorm3(x)
        x = self.activation2(x)
        x = self.pool2(x)
        x = self.dropout2(x)

        # Flatten
        x = x.view(x.size(0), -1)

        # Regression
        x = self.fc(x)

        return x.squeeze()
```

```python
def augment_eeg(x, mode='train'):
    if mode == 'train':
        # Time shift
        shift = np.random.randint(-50, 50)
        x = np.roll(x, shift, axis=1)

        # Amplitude scale
        scale = np.random.uniform(0.9, 1.1)

        # Noise
        noise = np.random.randn(*x.shape) * 0.05 * x.std()
```
