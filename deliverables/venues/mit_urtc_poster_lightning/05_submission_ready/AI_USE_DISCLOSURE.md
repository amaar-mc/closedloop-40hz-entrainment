## Statement

I used AI tools in two ways, and I want both to be clear.

**Software engineering.** While building this project I used AI coding assistants to help debug, look up how libraries work, and speed up routine implementation — the way I would use a reference book or ask a teaching assistant. I designed the analysis pipeline, chose the model and the features, decided the experiments, and wrote and checked the analysis myself. Every number on this poster comes from code I understand and can run on the OpenNeuro ds005048 dataset.

**Writing.** I used an AI writing assistant to help draft and revise the text of this extended abstract and talk. I directed the content, provided every number and its source, verified each claim against my own results, and made the final wording decisions. The scientific claims, their limits, and the interpretation are my own.

**What AI did not do.** It did not design the study, run or interpret the analysis, produce or change any data or result, or decide what this work claims. All citations were checked by hand against the original papers.
